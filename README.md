# ✈️ Airline Customer Analytics & Predictive Modeling

This repository contains data analytics and machine learning projects focused on airline customer behavior prediction and lounge eligibility assessment.

---

## 📌 Project Overview

This project addresses key business challenges in the airline industry through data-driven insights and predictive modeling:

1. **Predicting Customer Buying Behavior:** Building a machine learning model to predict whether a customer will complete a flight booking based on historical interaction and booking data.
2. **Heathrow Terminal 3 Lounge Eligibility:** Analyzing customer access rights and modeling eligibility criteria for airport lounge services.

---

## 🛠️ Tech Stack & Tools Used

* **Programming Language:** Python 🐍
* **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
* **Data Processing & ML:** Data Cleaning, Feature Engineering, Classification Models, Model Evaluation
* **Presentation & Reporting:** PowerPoint Executive Presentation 📊
